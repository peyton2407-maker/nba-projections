Host (static, free options):

  • GitHub Pages — push the HTML + JSON
  • Netlify / Vercel — drag-and-drop the folder
  • Cloudflare Pages

This file is fully self-contained. Open it locally or host the folder. After games start, re-run the pipeline and refresh.
